既存スキルの編集依頼を受け付ける。本スキルの責務は「他スキルへの影響調査」であり、編集作業そのものは行わない。編集と編集後の効果測定は `anthropic-skills:skill-creator` に委ねる。

責務を分ける理由: 編集を本スキルが直接行うと、変更の効果を測らないまま SKILL.md が書き換わる。skill-creator は旧版との比較実行と評価ループを持つので、編集はそちらに一本化し、本スキルは skill-creator が持たない「他スキルからの参照」の観点だけを担う。

## 引数
$ARGUMENTS

## 引数の形式

```
<スキル名> <変更内容の説明>
```

- **スキル名**: 対象スキルの名前（ディレクトリ名）
- **変更内容の説明**: 変更指示（自然言語）

## スキルファイルの配置

- ユーザースコープ: `~/.claude/skills/<skill-name>/SKILL.md`
- プロジェクトスコープ: `.claude/commands/<skill-name>.md`

## 実行手順

### 1. 対象スキルの確認

対象スキルのファイルを読み込み、現在の内容を把握する。存在しない場合はエラーを報告して終了。

### 2. 影響調査

対象スキルの名前で、他のスキルからの参照を検索する。Grepツールを使用：

- `~/.claude/skills/` 配下の全 `*.md` ファイルからスキル名を検索
- `.claude/commands/` 配下の全 `*.md` ファイルからスキル名を検索（存在する場合）

以下の参照パターンを確認する：
- 他のスキルの本文中での名前の言及（例: 「`comment-issue` スキルを使って」）
- `allowed-tools` に `Skill` を含むスキルからの呼び出し可能性

調査結果を報告する：
- **参照あり**: どのスキルからどのように参照されているかを一覧で示す。変更内容が参照元の期待（引数形式・出力・責務）を壊すかを併せて述べる
- **参照なし**: 他スキルへの影響なしと報告

参照元の期待を壊す変更であれば、編集に進む前にユーザーへ確認する。

### 3. skill-creator への委譲

影響調査の結果を添えて、Skill ツールで `anthropic-skills:skill-creator` を呼び出す。渡す情報：

- 対象スキルのパス
- 変更内容の説明（引数で受けたもの）
- 影響調査の結果（参照元と、変更時に維持すべき期待）

skill-creator には「既存スキルの改善」として扱わせる。すなわち、編集前のスナップショットを取り、編集後にテストプロンプトを旧版・新版の両方で実行して比較する（skill-creator の「Improving the skill」の手順）。効果測定を省略しない。変更が小さく見えても、旧版との比較がなければ改善したかどうかを判断できないからである。

効果測定のテスト実行に使うサブエージェントの model は、対象スキルの frontmatter の `model` に合わせる（未指定なら Agent ツールの既定）。スキルは本番でそのモデルで動くので、別のモデルで測った結果は本番の挙動を表さない。一方、採点や集計のような機械的な作業は `haiku` で足りる。

### 4. 結果の報告

skill-creator の結果（変更差分、効果測定の結果）をユーザーに提示する。影響調査で参照元があった場合は、参照元の期待が維持されているかを効果測定の結果から確認して報告する。

## 注意事項

- 本スキルは SKILL.md を直接編集しない。編集は必ず skill-creator を経由する
- 影響調査は省略しない
- 効果測定は省略しない。ユーザーが明示的に省略を指示した場合のみ、その旨を報告したうえで省く
