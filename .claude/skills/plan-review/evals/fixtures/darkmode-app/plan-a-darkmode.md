# ダークモード対応 実装計画

## 目的

サイト全体をダークモードに対応させる。OS の設定に追従し、ユーザーが手動で切り替えもできるようにする。

## 前提

- 既存の `useTheme` フックがテーマの現在値を返すので、これを拡張して使う
- 色は CSS 変数で管理する

## 手順

### 1. テーマの型を増やす

`useTheme` の戻り値に `dark` を追加する。

### 2. カラートークンを定義する

`src/styles/globals.css` にダーク用の色を追加する。既存のライト用の値を見ながら、コントラストが足りるようによしなに調整する。

### 3. 各コンポーネントを対応させる

`src/components/` 配下のコンポーネントを、ハードコードされた色から CSS 変数参照に置き換える。数が多いので適切に進める。

### 4. 切り替え UI を置く

ヘッダーにトグルを追加する。デザインは既存のボタンに合わせる。

### 5. 選択の永続化

ユーザーが選んだテーマを保存する。保存方式（localStorage か Cookie か）は後で詰める。

### 6. OS 設定への追従

`prefers-color-scheme` を見て初期値を決める。ユーザーが手動で切り替えていた場合の優先順位は実装時に判断する。

## 完了条件

ダークモードに切り替えたときに、全ページが破綻せず読めること。
