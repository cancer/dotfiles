# 観測済みの失敗

このレビューが検査するのは、以下の会話で実際に起きた失敗に対応する項目である。

| ID | 失敗 | 出典 | 対応 |
|---|---|---|---|
| F1 | 読者役の改善案を取り込み、受注前の無償実データ検証を約束した | Codex のユーザー発言「先方担当者のリアクションをシミュレーションしたら…無償と明記する」、handoff §2「絶対に受注前の無償実データ検証を約束しない」 | J-unagreed |
| F2 | 技術者向けの言葉が残り、非技術者の読者に通じなかった | Codex「所々技術者向けのワードが出てきてるけど」 | R-tech-terms |
| F3 | 先方が知らない製品名をそのまま書いた | handoff §2「先方はCloudflareの製品名を知らないため」 | J-unknown-names |
| F4 | 「拡張」「対象外」「今回含まないもの」「追加予算でご相談する機能」のような、断る・追加料金を求める印象の語を使った | handoff §2 | R-words-negative |
| F5 | ヒアリングしていない論点（同時編集の競合対策）を提案に足した | Codex「競合が起きうるかどうかってヒアリングの内容に入ってないんだよね」 | J-scope |
| F6 | 見出しから何を伝えたいか分からなかった | Codex「基本構成って何を伝えたいの？」 | J-heading |
| F7 | 形式を変えたときに文言が変わった | Claude セッション 19843cb7「文言が変わってしまってるところがないか調べて」 | R-deck-diff |
| F8 | 社内向けの注記「社内検討用・金額等は調整中」が対外資料に残った | Claude セッション 19843cb7「これ消して」 | R-internal |
| F9 | 合意していない費用負担を提案した（サーバー代を弊社負担に） | Claude セッション 2269f83e「サーバー代は弊社が負担する。つまり…持ち出しなさい、と？」 | J-unagreed |
| F10 | ユーザーが否定した時間計測を提案に入れた | handoff §2「時間計測はしない（ユーザーの明示訂正）」 | J-unagreed |
| F13 | 依頼内容と無関係な企業情報（業績など）を提案の根拠にした | state.txt のユーザー発言「最近の業績が◯◯なので、XXするといいです…は認めない」 | J-unrelated |
