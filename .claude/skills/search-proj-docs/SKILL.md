## 概要

CLAUDE.mdやREADMEからプロジェクトのドキュメントディレクトリを特定し、キーワードでドキュメントを検索する。

## 引数

$ARGUMENTS

- 引数なし: ドキュメント一覧を表示
- キーワード: ドキュメント全体からキーワード検索
- `inbox キーワード`: inboxディレクトリも含めて検索
- `inbox`: inboxも含めた一覧を表示

## 手順

### 1. ドキュメントディレクトリの特定

CLAUDE.mdとREADME.md（ルートおよび主要サブディレクトリ）を読み、ドキュメントが格納されているディレクトリパスを判断する。以下のようなヒントを探す:

- `docs/` や `documentation/` への言及
- ディレクトリ構造の説明内でドキュメント系と読み取れるパス
- 「仕様書」「ADR」「設計」「アーキテクチャ」等の記述に紐づくパス

見つからない場合はユーザーに「ドキュメントディレクトリを特定できませんでした」と報告して終了する。

### 2. 検索対象の決定

特定したドキュメントディレクトリ配下の全ディレクトリが検索対象。ただし:

- `inbox` という名前を含むディレクトリは、引数に `inbox` が指定された場合のみ対象に含める
- 通常は `inbox` を除外する

### 3a. 引数なし（一覧モード）

ドキュメントディレクトリ配下の `.md` ファイルを Glob で取得し、カテゴリ（ディレクトリ）別に一覧表示する。

出力形式:

```
## ドキュメント一覧

### specs
- specs/0001-individual-subscription.md - 個人購読
- specs/0002-team-subscription.md - チーム購読

### reference/adr
- reference/adr/0001-adopt-adr.md - ADR採用
```

各ファイルのタイトルはfrontmatterの `title` またはファイル内最初の `#` 見出しから取得する。どちらもなければファイル名をそのまま使う。

### 3b. キーワード指定（検索モード）

Grep でドキュメントディレクトリ配下を検索する。ヒットしたファイルごとに以下を出力する:

```
## 検索結果: "決済"

1. specs/0001-individual-subscription.md (L42, L78)
   - L42: PAY.JPを利用した決済フローの定義
   - L78: 決済失敗時のリトライ処理

2. architecture/er.md (L120)
   - L120: 決済関連テーブルのリレーション
```

- ファイルパスはドキュメントディレクトリからの相対パスで表示
- 各ヒット行の前後の文脈から、その行が何について述べているかを簡潔に添える
- ヒットがなかった場合は「該当するドキュメントは見つかりませんでした」と報告
