既存スキルを削除します。

## 引数
$ARGUMENTS

## 引数の形式

```
<スキル名>
```

- **スキル名**: 対象スキルの名前（ディレクトリ名）

## スキルファイルの配置

- ユーザースコープ: `~/.claude/skills/<skill-name>/SKILL.md`
- プロジェクトスコープ: `.claude/commands/<skill-name>.md`

## 実行手順

### 1. 対象スキルの確認

対象スキルのファイルを読み込み、現在の内容を表示する。存在しない場合はエラーを報告して終了。

### 2. 影響調査

対象スキルの名前で、他のスキルからの参照を検索する。Grepツールを使用：

- `~/.claude/skills/` 配下の全 `*.md` ファイルからスキル名を検索
- `.claude/commands/` 配下の全 `*.md` ファイルからスキル名を検索（存在する場合）

以下の参照パターンを確認する：
- 他のスキルの本文中での名前の言及（例: 「`comment-issue` スキルを使って」）
- `allowed-tools` に `Skill` を含むスキルからの呼び出し可能性

調査結果を報告する：
- **参照あり**: どのスキルからどのように参照されているかを一覧で示し、削除による影響を警告
- **参照なし**: 他スキルへの影響なしと報告

### 3. 削除

1. ユーザーに削除の最終確認を取る（参照の有無にかかわらず）
2. 承認されたらスキルのディレクトリごと削除する：
   ```bash
   rm -rf ~/.claude/skills/<skill-name>
   ```

## 注意事項

- 削除は不可逆操作のため、必ずユーザーの確認を取ること
- 参照がある場合は影響範囲を明示し、ユーザーが判断できる情報を提供すること
- 影響調査は省略しないこと
