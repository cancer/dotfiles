# 挿絵依頼文の雛形

`<...>` を埋めて `delegate-to-codex` 経由で Codex に渡す。挿絵の描く内容は、対象スライドの `outline.md` の原文を使う。

```text
このスライドに使う挿絵を 1 枚作成してください。

対象スライド: <S<n> と outline.md の見出し>
描く内容（outline.md の原文）: <挿絵指定をそのまま転記>
先方が使う具体的な名前: <outline.md にある具体名をそのまま転記>

条件:
- 挿絵にキャッチコピーや文字情報を入れない。
- 「作業A」のような抽象名を使わず、先方が使う具体的な名前を使う。outline.md に具体名がなく、挿絵に名前が必要なら、名前を創作せず A への差し戻し事項として deck-gaps.md に書いて停止する。
- 人物を描く場合も、顔・目を描かない。
- 矢印やアイコンなどの記号を使う場合は、それぞれが何を意味するかを描写内容に明記する。意味を説明できない記号は入れない。
```

抽象名、人物の顔・目、意味の分からない記号、挿絵のキャッチコピーが生じた過去の失敗に対応する（F11）。
